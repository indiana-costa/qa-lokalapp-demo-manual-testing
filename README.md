# 🧪 QA Manual Testing — Lokal App

Proyecto de pruebas manuales desarrollado con el objetivo de practicar y demostrar conocimientos en **Quality Assurance (QA)**, incluyendo planificación, creación de escenarios y casos de prueba, ejecución, documentación y análisis de resultados.

## 🎯 Objetivo

Validar las principales funcionalidades de Lokal App mediante pruebas manuales, utilizando diferentes escenarios funcionales y validaciones de datos, precios, productos y pedidos.

## 🌐 Aplicación probada

**Lokal App** — aplicación web de demostración para la selección y personalización de productos y la generación de pedidos por WhatsApp.

🔗 [Lokal App Demo](https://lokalapp.com.ar/)

## 🔍 Alcance de las pruebas

Se evaluaron las siguientes funcionalidades:

- Agregar, eliminar y modificar productos en el carrito
- Validar precios individuales y totales
- Personalizar productos con ingredientes extra
- Agregar y eliminar acompañamientos
- Ingresar y validar los datos del cliente
- Seleccionar la modalidad de delivery
- Validar la tarifa de delivery
- Seleccionar la opción de retiro en tienda
- Validar los importes totales de la compra
- Verificar la información del pedido
- Ingresar observaciones del pedido
- Validar la generación del pedido para WhatsApp

## 🧪 Tipos de pruebas

- Pruebas funcionales
- Pruebas positivas
- Pruebas negativas
- Validación de campos obligatorios
- Validación de precios y cálculos
- Pruebas de flujo de compra
- Validación de la información del pedido
- Verificación de la integración con WhatsApp

## 📊 Resultado de la ejecución

Se documentaron **25 casos de prueba**, distribuidos en siete áreas funcionales.

| **Área funcional** | **Casos** |

| Personalización del producto | 5 |
| Datos del cliente | 6 |
| Delivery | 3 |
| Retiro en tienda | 3 |
| Pedido | 2 |
| WhatsApp | 1 |
| **Total** | **25** |

Los resultados de ejecución se encuentran documentados en el informe de pruebas y en la planilla de casos de prueba.
