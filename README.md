# Proyecto de QA — Hamburguesería

## Descripción
Proyecto de pruebas manuales realizado para evaluar las principales funcionalidades de un sitio web de hamburguesería y verificar la correcta generación de pedidos para WhatsApp.

## Objetivo
Validar el funcionamiento de las funcionalidades principales del sitio, identificar posibles defectos y documentar los resultados de las pruebas.

## Alcance
- Navegación por el sitio web.
- Visualización y selección de productos.
- Validación de los datos del cliente.
- Generación del pedido para WhatsApp.
- Verificación de la información de los productos y del cliente.

## Tipo de pruebas
- Pruebas funcionales.
- Pruebas positivas y negativas.
- Pruebas de validación.
- Pruebas exploratorias.

## Entorno de pruebas
- Sistema operativo: Windows.
- Navegador: Google Chrome.
- Ejecución: manual.

## Herramientas utilizadas
- Microsoft Excel: documentación de casos de prueba y registro de resultados.
- Visual Studio Code: edición de la documentación.
- Git y GitHub: control de versiones y publicación del proyecto.

## Documentación

- Hoja de cálculo Excel: casos de prueba y resultados de ejecución.
